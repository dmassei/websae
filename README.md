# SAE — Sitio web

Rediseño del sitio de **SAE** (tecnología en insumos abrasivos para la industria), con un lenguaje visual editorial inspirado en rolex.com.

Sitio estático: HTML + CSS + JS, sin framework.

## Estructura
- `index.html` — inicio (hero + transición a cartas de producto)
- `productos.html` — catálogo
- `empresa.html` — historia de la empresa
- `contacto.html` — datos y formulario
- `css/styles.css`, `js/main.js`, `img/`

## Ver localmente
```bash
python3 -m http.server 8777
```
Luego abrir http://localhost:8777
